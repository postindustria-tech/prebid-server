Prebid.js sends ext.prebid.as: {"ap": true, "apb": ["simadapter"]} because of allowPriorityBids: ['simadapter']. Prebid Server keeps valid deals from simadapter and sets source: "adserver".

The deal on slot-6 has no cpm, so Prebid Server removes it and keeps the bid. To see the reason, open the developer tools, select Network, click the auction request and find ext.debug.as.stripped in the response.

Delete allowPriorityBids from this page to see Prebid Server remove every deal.
